Карта запишет общий файл sync-state.json в папку «Синхронизация». Обычный пароль от почты не подойдёт — нужен пароль для внешних приложений. На устройстве он не сохраняется.

Создать: Настройки → Безопасность → Пароли для внешних приложений (нужен привязанный телефон). Права: доступ к Облаку / полный доступ.
